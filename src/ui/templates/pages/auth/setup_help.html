Recovery options

{# Recipe 1 — visit signup #}

1. Create your account via /signup

canonical

First-time setup on a self-hosted instance is signup-driven. The form is enabled while the User table is empty. 

# Open in your browser:
http://localhost:8003/login?mode=signup

# Or hit the API directly (replace [email protected] / your-12+-char-password):
curl -X POST http://localhost:8003/api/v1/auth/signup \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d '[email protected]&password=your-12-char-password'
{# Recipe 2 — Check orchestrator logs #}

2. App not responding? Check orchestrator logs

debug

If /login doesn't load at all, Postgres or alembic likely failed. The orchestrator multiplexes [db] / [migrate] / [app] log lines. 

# Tail the orchestrator output. If [migrate] errored, fix that first.
nix run .#dev
{# Recipe 3 — Drop the dev DB #}

3. Reset everything and start fresh

destructive

Wipes the local Postgres data so you can sign up again from a clean slate. Loses any locally-entered data. 

rm -rf .naavik/db
nix run .#dev
