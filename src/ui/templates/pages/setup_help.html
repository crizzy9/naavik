{# ── Recovery recipes ─────────────────────────────────────────────── #}

Recovery options

{# Recipe 1 — nix run .#dev preferred #}

1. Restart with nix run .#dev (recommended)

canonical

The dev orchestrator exports NAAVIK_DEBUG=1 and runs the seeder, so the dev-credentials file lands automatically. 

# Stop the current server, then:
nix run .#dev

# Once the app starts:
cat ~/.naavik/dev-credentials
{# Recipe 2 — Set NAAVIK_DEBUG manually #}

2. Set NAAVIK_DEBUG=1 + restart

manual

Tells the seeder to write the dev-credentials artifact at next boot. The seeder only writes when no User row exists, so you may also need recipe 3. 

export NAAVIK_DEBUG=1
# (then restart the server)
uv run fastapi dev src/main.py
{# Recipe 3 — Drop + re-seed #}

3. Drop the dev DB + re-seed (last resort)

destructive

Wipes the local Postgres data + dev-credentials file so the seeder runs fresh. Loses any locally-entered data. 

rm -rf .naavik/db
rm -f {{ state.dev_credentials_path }}
NAAVIK_DEBUG=1 nix run .#dev
{# Recipe 4 — Multi-user signup #}

4. Enable multi-user signup (cloud / shared instance)

alt

If you can sign in with the existing account, flip Settings · Deployment → Allow multiple users. The signup form will then render on /login?mode=signup for everyone.
