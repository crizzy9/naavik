How LLM providers work

API keys are configured via environment variables in .env, not through this UI (vault deprecated in 0.2.0.01). Set ANTHROPIC_API_KEY, OPENAI_API_KEY, or OLLAMA_BASE_URL, then restart Naavik to pick up the change. Precedence is ANTHROPIC > OPENAI > OLLAMA when multiple are set. The model dropdown below is the only operator-mutable preference on this tab.

{% if _unconfigured %} {# No provider configured anywhere — LLM-dependent features will skip. #}

No LLM provider configured

Set at least one of ANTHROPIC_API_KEY, OPENAI_API_KEY, or OLLAMA_BASE_URL in .env and restart. Without one, resume tailoring, cover-letter drafting, and scoring will skip silently.
