## Why

17 small items shipped through `/build` as 17 individual plans would burn ~10x the token budget of one batched plan. Per `.claude/agents/manager.md § Batching small tasks`: the cap is 10 items per plan, but the unit-cost trade-off + the "extended autonomy + ship by morning" directive justifies one cap-flexed batch. All 17 items are mechanical follow-ups (rate limits, defensive parsing, doc graduations, test-infra cleanup, UI wiring). None introduces a design decision. None touches `src/cli/` or vault.

## Slicing rationale

Single batch (not split into 2 PRs):

1. **Total LOC ≈ 437** (~30 LOC × 14 + ~80 LOC × 3) — well within engineer dispatch capacity (~400-600 LOC comfortable).
2. **No surface overlap** — 15 distinct files / file-groups. Engineer can land 17 thematic commits without one item blocking another.
3. **Review cost: one parallel reviewer pair** vs two. One PR splits hacker + architect context across two reviews; one PR keeps the full cleanup story in one diff.
4. **Owner directive is "club these together"** — splitting fights the directive without buying coherent boundary.
5. **No security ordering required** — the HIGH-priority item (0.3.3.15 screener IDOR) is independent of the rest; it ships in the same PR but doesn't block any other follow-up.

**Build sequence guidance (engineer)**: land as 17 commits in priority order. Commit 1 is the HIGH-priority security fix (0.3.3.15); commits 2-9 are MEDIUM-priority security / correctness; commits 10-17 are LOW-priority polish + docs. One commit per row. No combined commits. (Engineer judgement allowed if two items share a single file edit AND one is < 5 LOC — e.g. 0.3.3.19 `score_aggregate_daily` is 2 LOC inside `scheduler/jobs.py`; if combined with another sibling row touching the same file, both go in one commit with a clear message.)

1. New module `src/services/rate_limit.py`:
   ```python
   """Generic per-user in-memory rate limiter. Mirrors auth.py:354-380.
   Single-instance MVP; cloud-tier multi-instance migration deferred to 0.4.x."""
   from __future__ import annotations
   from collections import deque
   from dataclasses import dataclass, field
   from datetime import UTC, datetime, timedelta

   @dataclass(slots=True)
   class RateLimit:
       window: timedelta
       threshold: int
       buckets: dict[int, deque[datetime]] = field(default_factory=dict)

       def record(self, user_id: int) -> None:
           bucket = self.buckets.setdefault(user_id, deque())
           now = datetime.now(UTC)
           cutoff = now - self.window
           while bucket and bucket[0] < cutoff:
               bucket.popleft()
           bucket.append(now)

       def is_limited(self, user_id: int) -> bool:
           bucket = self.buckets.get(user_id)
           if not bucket:
               return False
           cutoff = datetime.now(UTC) - self.window
           while bucket and bucket[0] < cutoff:
               bucket.popleft()
           return len(bucket) >= self.threshold

       def reset(self, user_id: int | None = None) -> None:
           if user_id is None:
               self.buckets.clear()
           else:
               self.buckets.pop(user_id, None)
   ```
2. Module-level singletons:
   ```python
   RESCORE_LIMIT_MIN = RateLimit(window=timedelta(minutes=1), threshold=10)
   RESCORE_LIMIT_HR  = RateLimit(window=timedelta(hours=1), threshold=60)
   ```
3. FastAPI dep `check_rescore_rate_limit(_user = Depends(require_authed_session))` that calls `is_limited` on both; raises `HTTPException(429, detail="rate limited")` w/ `Retry-After` header set to `int(window.total_seconds())`; on pass, calls `record` on both.
4. Wire into `src/api/jobs.py` rescore route via `Depends(check_rescore_rate_limit)`.

def _parse_scored_at(raw: Any) -> datetime | None:
    """Tolerant parse of `match_breakdown.scored_at` (string OR datetime).

    Stricter than the original — exotic non-ISO 8601 strings return None
    rather than producing best-guess UTC values that mislead the sparkline.
    """
    if raw is None:
        return None
    if isinstance(raw, datetime):
        return raw if raw.tzinfo else raw.replace(tzinfo=UTC)
