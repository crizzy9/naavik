#### A.2 · Service function — `application_service.cleanup_stale_drafts`

New function in `src/services/application_service.py` (~25 LOC):

```python
async def cleanup_stale_drafts(
    session: AsyncSession,
    *,
    older_than_days: int = 30,
) -> int:
    """Archive DRAFTs idle > N days. Returns count archived.

    Idleness = Application.updated_at older than threshold AND
    Application.status == DRAFT AND deleted_at IS NULL. Matches
    discard_draft semantics (CLOSED+withdrawn_by_me+soft-delete);
    emits CLEANUP_STALE STATUS_CHANGE event so the audit trail shows
    "system archived" vs "user discarded".
    """
    threshold = datetime.now(UTC) - timedelta(days=older_than_days)
    stmt = select(Application).where(
        Application.status == ApplicationStatus.DRAFT,
        Application.deleted_at.is_(None),
        Application.updated_at < threshold,
    )
    rows = (await session.exec(stmt)).all()
    archived = 0
    for app in rows:
        now = datetime.now(UTC)
        app.status = ApplicationStatus.CLOSED
        app.closed_reason = ClosedReason.WITHDRAWN_BY_ME
        app.deleted_at = now
        app.updated_at = now
        session.add(app)
        await _emit_event(
            session,
            user_id=app.user_id,
            application_id=app.id,
            kind=AppEventKind.STATUS_CHANGE,
            payload={
                "from": ApplicationStatus.DRAFT.value,
                "to": ApplicationStatus.CLOSED.value,
                "trigger": StatusChangeTrigger.CLEANUP_STALE.value,
            },
        )
        archived += 1
    if archived:
        await session.flush()
    return archived
```

New `StatusChangeTrigger.CLEANUP_STALE` enum value in `src/models/enums.py` (existing enum; one-line addition). No migration needed — `StatusChangeTrigger` is consumed via `AppEvent.payload` JSON, not stored as a SQL ENUM column.

#### B.2 · New route — `POST /api/v1/jobs/manual`

Lives in `src/ui/routes/jobs.py` (existing module; jobs router already mounted at `/api/v1/jobs/...`). ~40 LOC:

```python
@router.post("/api/v1/jobs/manual", name="jobs_manual")
async def post_job_manual(
    payload: Annotated[dict[str, Any], Body()],
    session: AsyncSession = Depends(get_session),
    current_user: User = Depends(require_password_complete),
):
    """Create a manually-entered Job. Reads JobCreate fields from form body."""
    company = (payload.get("company") or "").strip()
    role = (payload.get("role") or "").strip()
    description = (payload.get("description") or "").strip()
    if not (company and role and description):
        raise HTTPException(status_code=422, detail="company, role, description required")

    try:
        job_create = JobCreate(
            company=company,
            role=role,
            description=description,
            url=payload.get("url") or None,
            location=payload.get("location") or None,
            remote_policy=RemotePolicy(payload.get("remote_policy", "UNKNOWN")),
            source=JobSource(payload.get("source", "MANUAL")),
            board=ApplicationBoard.MANUAL,
        )
    except ValueError as exc:
        raise HTTPException(status_code=422, detail=str(exc)) from exc

    job = await job_service.create_manual_job(session, job_create, user_id=current_user.id)
    await session.commit()
    response = Response(status_code=204)
    response.headers["HX-Redirect"] = "/tracking"
    return response
```
