## Hand-back format

When done, hand back:

1. **Branch + PR URL** (`gh pr create` using `.github/pull_request_template.md`).
2. **File list** — every file in the deliverables table above + any deviations.
3. **Playwright screenshot paths** — desktop + mobile per quality-bar.
4. **Test count** — `uv run pytest` summary line.
5. **Deviations summary** — bullet list of every place the shipped code diverges from this plan or `docs/plans/49-...md` § D. Each bullet carries:
   - **What** changed (one-line)
   - **Why** (constraint that forced the change)
   - **Impact** on dependent plans (0.2.5.04 / 0.2.5.05 / 0.2.5.06 / 0.2.0.10a)
   - **Surface** any new env var / CLI command / on-disk path / port / schedule introduced
6. **Follow-up notes** — anything noticed during implementation that warrants a new ROADMAP row (manager files via BOOKKEEPING).
7. **Manager handoff line** — `BUILT files=<n> tests=<n> deviations=<n> summary='<one-line>'` (per `docs/AGENT_OPS.md § 7.2`).

The hand-back's **deviations summary** is the contract for plan archival — without it, the plan cannot move to `docs/plans/archive/`. The implementer (you) appends `[ISO-ts] DEVIATION plan=docs/plans/49-...md what=<...> why=<...> impact=<...>` lines to `traces/<run-id>/engineer-deviations.log` the moment any divergence becomes apparent during implementation (per `engineer-deviation-log` skill), NOT at end of run.
