# Visual QA snapshots

Generated by `tests/visual/capture.py` per plan 09 § E.

**Generation requires the Nix dev shell** (which provides Chromium + dynamic
loader patches via `playwright-driver.browsers`). Bare NixOS Python venvs
can't launch the upstream Playwright binaries.

```bash
# Boot dev server
NAAVIK_DEBUG=1 uv run fastapi dev src/main.py

# In a second terminal (inside `nix develop`):
uv run python tests/visual/capture.py

# Or per-screen:
uv run python tests/visual/capture.py --screen=login
```

20 baseline PNGs land here on first run (10 logical screens + bullet modal +
extra Discover-review variants × 2 viewports). Naming convention:
`<screen>-<viewport>.png` where `viewport ∈ {desktop, mobile}`.
